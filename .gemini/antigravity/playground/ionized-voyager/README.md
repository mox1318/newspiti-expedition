# Spiti Expedition | The Dark Horizon

A Neo-Brutalist travel experience designed for the modern explorer.

## 🚀 Deployment

### Deploy to Vercel

1. **Go to [Vercel Dashboard](https://vercel.com/new)**.
2. Click **Import** next to `newspiti-expedition`.
   - *If you don't see it, ensure Vercel has permissions to access your repositories.*
3. Click **Deploy**.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: GSAP + Lenis Scroll
- **Design System**: "Midnight Aurora" (Neo-Brutalism)

## ⚡ Features

- **Kinetic Typography**: GSAP-powered text reveals.
- **Smooth Scrolling**: Integrated Lenis for premium feel.
- **Horizontal Gallery**: Pinned scroll interactions.
- **Immersive Audio/Visuals**: Dark mode default.

## 🏃‍♂️ Run Locally

```bash
npm install
npm run dev
```
